# Portfolio Full-Stack Content Router

Node project for full-stack/product and frontend resumes. It filters portfolio projects by role variant and stack accent, exposes JSON endpoints, and serves a small browser dashboard without external dependencies.

## Series Coverage

- Full-stack/product: data routing, HTTP service, browser rendering.
- Frontend/web: client-side rendering and content selection UX.
- Backend/platform: deterministic API responses that mirror the Hugo content model.

## Run

```powershell
npm start
```

Open `http://localhost:4177/?variant=fullstack-product&accent=node`.

## Test

```powershell
npm test
```
